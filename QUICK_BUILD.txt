ESP-IDF Link - Docker-Based Build - Quick Reference
===================================================

REQUIREMENTS:
  - Docker installed and running
  - USB cable for device flashing (optional)

FIRST TIME SETUP:
  bash setup.sh

BUILD PROJECT:
  bash build.sh

DO NOT BUILD WITH DOCKER-COMPOSE HERE:
  docker-compose.yml still defines build/shell/flash/monitor services, but on this
  project's WSL2 + Docker Desktop setup Compose runs hang indefinitely (>30 min)
  when only sources changed. bash build.sh and the "docker run" forms below go
  straight to the Docker daemon; reach for Compose only when you are debugging
  Compose itself.

FLASH TO DEVICE (replace /dev/ttyUSB0 with your port):
  docker run --rm --device=/dev/ttyUSB0 \
    -v $(pwd):/project \
    esp-idf-link \
    bash -c "source /opt/esp/idf/export.sh && idf.py -p /dev/ttyUSB0 flash"

MONITOR SERIAL OUTPUT:
  docker run --rm -it --device=/dev/ttyUSB0 \
    -v $(pwd):/project \
    esp-idf-link \
    bash -c "source /opt/esp/idf/export.sh && idf.py -p /dev/ttyUSB0 monitor"

INTERACTIVE SHELL IN CONTAINER:
  docker run --rm -it \
    -v $(pwd):/project \
    esp-idf-link \
    bash

FLASH WITHOUT A LOCAL BUILD (no Docker needed):
  CI builds every push and, on a green main, commits build/link-idf-example.bin,
  build/bootloader/bootloader.bin and build/partition_table/partition-table.bin
  to the branch. A clean clone carries flashable images already:
    node flash-ticker.js COM3

  The SPIFFS image holding the MIDI files is separate -- flash_midi_data.sh builds
  it from ./data and writes it at 0x317000.

CLEAN BUILD:
  rm -rf build/
  bash build.sh

FULL DOCKER IMAGE REBUILD:
  docker build --no-cache -t esp-idf-link .
  bash build.sh

BUILD ARGUMENTS:
  bash build.sh          # incremental
  bash build.sh clean    # rm -rf build/ first
  # build/ is hardcoded -- build.sh accepts no BUILD_DIR override
  # override the image with IMAGE_NAME=... IMAGE_TAG=... bash build.sh

BUILD AND FLASH IN ONE COMMAND:
  bash build.sh && docker run --rm --device=/dev/ttyUSB0 \
    -v $(pwd):/project \
    esp-idf-link \
    bash -c "source /opt/esp/idf/export.sh && idf.py -p /dev/ttyUSB0 flash"

DOCKER CLEANUP:
  docker image rm esp-idf-link:latest
  docker image prune  # Clean unused images

KEY DIRECTORIES:
  - Project source:    Current directory
  - Build artifacts:   ./build/
  - Docker image:      esp-idf-link:latest

ADVANTAGES:
  ✓ No local ESP-IDF installation needed
  ✓ Pre-built WiFi binaries included
  ✓ Works on Windows, Mac, and Linux
  ✓ No filesystem permission issues on WSL2
  ✓ Consistent reproducible environment
  ✓ Easy cleanup - just delete the image
  ✓ CI commits the three images -- a clean clone flashes without Docker

TROUBLESHOOTING:
  - Docker not found:         Install from https://www.docker.com/
  - Daemon not running:       Start Docker Desktop
  - Permission on /dev:       sudo usermod -a -G dialout $USER
  - Slow on WSL2:             Use /home/user paths instead of /mnt/c
  - Build fails:              docker build --no-cache -t esp-idf-link .
  - Compose hangs:            use bash build.sh, not docker-compose run --rm build
